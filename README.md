## 这是什么？

「善友引擎」是一个 AI Skill，让你在与 AI 对话时，拥有一套完整的**李善友思维框架**。

它以**第一性原理**为根基，**第二曲线创新**为路径，**非连续性**为世界观，融合「理念世界」体系（美好作品→临在当下→生命游戏→使命召唤），以及「信念决定上限」的创业者心智模型。

v4 版本还整合了李善友 2026 年度大课核心内容：**能知革命**、**意识大模型**、**白蚁理论**、**以商入道**等最新理论。
